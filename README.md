# うなぎ屋かわすい「新仔うなぎ」早期予約キャンペーンLP

澤井珈琲様のLPレイアウトを引き継いで作成した、8月7日〜8月28日限定・新仔うなぎ早期予約キャンペーンの特集ページです。

公開URL: https://sakikohatakeyama.github.io/kawasui-shinko-unagi-campaign/

## ファイル構成

```
index.html          … 特集ページ本体(HTML+CSS+JS、すべてこの1ファイルに含まれています)
images/
  header/            … ヘッダーのロゴ画像(仮)
  hero/               … ファーストビューのメインビジュアル(看板画像)
  product/            … 商品写真
```

`index.html` を丸ごと(`images/` フォルダごと)サーバーにアップロードしてください。パスはすべて相対パスなので、どのディレクトリに置いても動作します。

## 設定済みの内容

- **早期予約期間**は 2026年8月7日 0:00〜8月28日 13:59 に設定済みです。
  - 開催前:「早期予約 受付開始まで あと○日○時間○分」
  - 開催中:「早期予約 受付終了まで あと○日○時間○分」(最終日は秒単位表示に切替)
  - 終了後:カウントダウンと予約ボタンが自動的に無効化されます
- ファーストビューの看板画像(`images/hero/fv-sp.jpg` / `fv-pc.jpg`)は、いただいた `unagi_kanban.jpg` をそのまま使用しています(PC・スマホ共通)。
- **予約受付ページURL**は `https://item.rakuten.co.jp/kawasui/10001879/` に設定済みです。ページ内の全「新仔うなぎを予約する」ボタンがこのURLにリンクします。
- 商品写真(蒲焼・白焼き・長焼き特大170g・白焼きパッケージ・早期予約W特典訴求)はいただいた `photo01.jpg`〜`photo05.jpg` を反映済みです。
- ヘッダーロゴはいただいた `logo.PNG` を反映済みです。ロゴをクリックすると `https://www.rakuten.co.jp/kawasui/`(かわすいトップページ)に遷移します。

## 実装上のご注意

- **JavaScriptを使用しています。** カウントダウン、予約URLの一括設定、紙吹雪演出にJSを使っています(澤井珈琲LPと同じ仕組みを踏襲しています)。JavaScriptが実行できない環境には設置できませんのでご留意ください。
- レスポンシブ対応済みで、スマホ表示を基準に作成し、768px以上でPC向けレイアウトに切り替わります。ファーストビューはPC・スマホとも同じ画像(縦長)を表示する仕様です。
- 見出し等のフォントに Google Fonts(Josefin Sans)を外部読み込みしています。インターネット接続がある環境であれば通常表示され、読み込めない場合は端末の標準フォントで表示されます。
- 「新仔うなぎとは?」ブロックの図解(稚魚漁→育成→池上げのタイムライン、ヒネ/新仔比較カード)は画像ではなくCSSで組んでいます。イラスト画像をご用意いただける場合はご相談ください。
- カラーパレットは ff9933(オレンジ)/ffcc99(ベージュ)/ffcc33(ゴールド)/cc0000(レッド)を基調にしています。本文テキストは黒、CTAボタンは黒背景で統一しています。
- 澤井珈琲LPにあった「販売実績カウンター(◯個突破)」機能は、本キャンペーンでは正式な実績数値がないため実装していません。必要であれば追加できます。
